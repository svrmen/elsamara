# ЭлектроСмета — мобильный режим

## Как собрать и запустить
- Приложение — статическая страница. Достаточно открыть `index.html` в браузере.
- Для локального сервера можно выполнить `python3 -m http.server 8000` в корне репозитория и открыть `http://localhost:8000/index.html`.

## Как проверять адаптивность
- Откройте DevTools в браузере (Chrome, Edge или Firefox) и включите эмуляцию устройств (Toggle device toolbar).
- Протестируйте ключевые ширины: **360 px**, **390 px** и **430 px**. Убедитесь, что «компактный режим» включается автоматически, элементы остаются кликабельными (≥44 px) и нижняя панель .totalsBar не перекрывает контент.
- Для настольных разрешений отключите эмуляцию, чтобы убедиться, что десктопная таблица и принт-версия не изменились.

## Скриншоты для PR
- После проверки сделайте скриншоты мобильных состояний (например, ширины 360 и 430 px) через DevTools.
- Добавьте файлы в PR (папка `artifacts/` или прикреплённые изображения) вместе с кратким описанием сценария, который отображает скриншот.
